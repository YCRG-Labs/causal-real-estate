# Code Review Report: Does Listing Language Add Value Beyond Location?

*Reviewed: 2026-07-12 | Languages: Python | Depth: main | Paper: causalrealestate.tex*

## Overall Assessment

This is unusually well-documented research code: nearly every script carries a citation-backed docstring explaining why a method or threshold was chosen, several narrate prior bugs and their fixes, and the master pipeline (`Makefile.jbes` + `run_pipeline_jbes.py`) has real reproducibility infrastructure (SHA-256 manifest-gated resumability, an explicit global seed, a hash-verification stage). Every headline number that has a direct downstream output file matched the manuscript to 2–4 significant figures. The issues worth checking are three: a dependency manifest that will fail a clean install, a leaky feature block in the composition-adjustment numbers, and a channel-inconsistent pooling convention behind the two headline effects.

## What's Working Well

- Docstrings carry real methodological content and citations (Gelbach 2016, Belrose 2023, Holstege 2025, Flury 1984, Voita-Titov 2020), not boilerplate.
- Self-critical framing is the norm: `shen_2021.py` labels itself "NOT a strict replication" and flags `published_se`/`published_n` as unverified placeholders; `leace_price_decomposition.py` documents a prior code-review bug and why the fix is correct.
- Deterministic seeding is pervasive (~495 seeded call sites across 72 files; per-iteration bootstrap seeds derived deterministically; global seed set before model imports).
- The master pipeline's manifest is SHA-256-verified, not just presence-checked — stronger resumability than most ad hoc pipelines.
- Headline point estimates trace cleanly to `results/` outputs: pooled Baur +0.125 = `theta_re`; NYC null; sale-price θ=−0.061, dof=9; counterfactual NDE +0.074; coverage 0.7367 at the large-effect cell; winsorization at median ± 5 MAD; 5-fold cross-fitting throughout.

## Code Quality Summary

The pipeline core (`Makefile.jbes`, `run_pipeline_jbes.py`) is the strongest part: staged, hash-verified, seeded. `leace_deconfound.py` is the largest, most multi-responsibility file (~1040 lines spanning LEACE, SPLINCE, IGBP, two probe families, MDL codelength, power, routing, self-test); internally well-documented with a `_self_test`, but harder to unit-test than a split would allow, and it is the file carrying the undeclared `concept-erasure` dependency. `make_fig_coords.py` breaks the portability convention with a hardcoded home directory. `run_pipeline_jbes.py:137-142`'s `smoke` target prints a reproduction target (95.1%/347) but only returns the subprocess exit code — confirm `confounder_escalation.py` asserts internally, else `make smoke` can pass green after a silent drift. Minor: an undocumented `geo_cols = cor > 0.99` threshold in `leace_price_decomposition.py:104`.

## Paper-Code Consistency

### Matched (HIGH)
- Pooled sBERT-PC1 +0.125 → `baur_pooled_pca.py`, `theta_re=0.12487`; "10 of 12 exclude zero" excludes NYC and Seattle.
- NYC covers zero (`dml_theta=-0.0088`); two-encoding Pearson 0.9140 → `cross_method_concordance.csv`.
- Sale-price θ=−0.06121, G_metro=10, dof=9 → `soldprice_twoway_cluster.json`; counterfactual NDE +0.07343; coverage 0.7367 at N=500, scm1_0.15.
- CoCA proposition/Monte Carlo/symbolic proof implemented as described.

### Items To Verify
- **Channel-inconsistent pooling convention.** Baur's quoted +0.125 = `theta_re` (random-effects); Shen's quoted +0.060 = `theta_fe` (fixed-effect), while Shen's own `theta_re` is 0.083. Confirm which convention the manuscript intends per channel — as written they are cited inconsistently within the same rollup framework.
- **Composition-adjustment leak.** `within_category_demean.py:84-96,142` computes the `raw`/`dummy`/`demean` thetas on `_zerofill_block` (missing beds/baths/sqft → 0), while the script's own AUC audit switches to `_impute_block` (median) precisely because a zero-fill "would turn into a perfect land classifier." The distortion the audit avoids is still present in `pct_attenuation_demean_*`, the paper's headline composition statistic. Independently flagged by the referee2 code audit.
- **69,173 not pinnable.** Summing per-city n's in `baur_pooled_pca_table.csv` gives 69,204; the paper's 69,173 is an intermediate dedup count not exposed in the reviewed scripts. (Matches the paper-side inconsistency the pre-submission review flags.)
- **Hotelling "rejects zero in all 12"** and **LEACE erasure magnitudes** — machinery present (`hotelling_t2_cross_method.py`, `leace_deconfound.py`) but the specific headline numbers were not cross-checked against their result files; confirm which p-value threshold (raw vs BH-FDR) underlies "all 12."
- **Ridge vs LightGBM nuisance** — confirm which backend underlies headline vs robustness tables (`--fast` ridge path vs the legacy `booster.py` path).
- **Crime coverage** — `attach_crime_to_parcels.py` skips Phoenix (no crime coordinates); if the data appendix implies uniform crime coverage, add the caveat.

### Not Found In Reviewed Files
- `build_active_confounders.py` / `attach_crime_to_parcels.py` are not in `run_pipeline_jbes.py`'s dispatch; they read/write `{city}_parcels_micro_geo.gpkg`, a different artifact than the Makefile's `confounders` stage. Confirm which is the live confounder-build path and document run order for the other.
- Load-bearing but outside the reviewed set: `spatial_basis.py`, `causal_inference.py`, `simulation/dgp.py`, `simulation/estimators.py` — worth a follow-up pass.

4. Fix the `make_fig_coords.py` hardcoded path; wire the meta/concordance/sensitivity/figure-generation steps (and `build_active_confounders.py`) into the master pipeline so "one command reproduces the paper" becomes true.
